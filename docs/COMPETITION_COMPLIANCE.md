## Technical requirements (OFFICIAL) → evidence

| Requirement | Evidence in this repo | Status |
|---|---|---|
| Select one chronic or lifestyle condition prevalent in India (e.g. T2D) | Type 2 diabetes, post-meal hyperglycaemia | ✅ |
| Fusion of **static/historical** data: "Simulated EHR (demographics, past diagnoses, lab results, genetic markers)" | `PatientRecord`: demographics, conditions, labs (HbA1c, FPG, eGFR, lipids), medications, **family history + TCF7L2 rs7903146 genotype (added wave 2, synthetic, display-only)** | ✅ (genetics is display-only; see note 1) |
| Fusion of **dynamic** data: simulated or open wearable/IoT time series (HRV, CGM, sleep stages, step count) | CGM every 5 min, steps, heart rate, meal logs | ✅ (no HRV or sleep yet; the list is "e.g.") |
| "A working algorithmic model that ingests these two streams and successfully predicts an adverse event (e.g. … glucose spike 2 hours in advance)" | 120-min excursion-onset model; `glucotwin train`; `reports/evaluation_report.json`; robustness audit `reports/audit_report.json` | ✅ (synthetic evaluation only) |
| "A conceptual UI dashboard showing how a doctor would interact with this virtual patient" | React dashboard with chronological replay (`docs/screenshots/`) | ✅ |
| Data: "strictly required to use anonymized, open-source, or synthetic datasets" | 100% synthetic, generated by `src/glucotwin/synth/generator.py`; no external data in repo | ✅ |

Note 1: the official list names genetic markers as an example of static EHR content. We include a synthetic genotype in the record. **We do not
claim it affects predictions:** the simulator gives it no physiological effect, and it is not a model feature (enforced by `tests/test_audit.py`).
